# Wordsy

Карточки для изучения английских слов с интервальным повторением.

**Открыть:** https://dan1eloff.github.io/wordsy/

## Что умеет

- Алгоритм повторения **FSRS-4.5** (как в современном Anki): 4 кнопки «Забыл / Трудно / Хорошо / Легко», на каждой видно, через сколько слово вернётся.
- Карточка: слово + пример → объяснение по-английски, перевод на русский и казахский спрятан.
- Интерфейс на трёх языках: қазақша, русский, English (переключатель в «Настройках» и на экране входа).
- Озвучка слова и примера (американская или британская).
- Обратные карточки: по объяснению напечатать слово.
- Серия дней, цель дня, XP, статистика и прогноз на неделю.
- Лимиты новых слов и повторений в день.
- Импорт списком (`слово ; объяснение ; пример ; русский ; қазақша` или Tab) и резервная копия в JSON.

## Как поставить на телефон

Открой ссылку в Safari → «Поделиться» → «На экран Домой».

## Синхронизация

Войди по почте и паролю: слова хранятся в Supabase (таблицы `words` и `profiles`, доступ только к своим строкам через RLS) и синхронизируются между устройствами в реальном времени. Без входа слова хранятся только в браузере.

Слово можно добавить без объяснения: оно помечается «ждёт Claude», и Claude дописывает объяснение, пример и перевод прямо в базе.

## Устройство

Один файл `index.html`, без сборки. Шрифт Nunito из Google Fonts, `@supabase/supabase-js` с jsDelivr.
